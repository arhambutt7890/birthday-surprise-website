# 🎂 Birthday Surprise Website

An interactive and visually engaging birthday surprise website designed to create a memorable digital celebration experience.

The project combines modern web design, animations, interactive sections, and responsive layouts to create a personalized and immersive experience.

## ✨ Features

- 🎉 Interactive birthday experience
- 💫 Smooth animations and transitions
- ❤️ Personalized celebration sections
- 📱 Fully responsive design
- 🎨 Modern and visually appealing UI
- 🖼️ Image-based interactive sections
- 🎵 Interactive multimedia experience
- ✨ Creative visual effects
- 💻 Optimized for desktop and mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- CSS Animations & Transitions
